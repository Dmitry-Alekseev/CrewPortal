# Crew Portal Change Log

## 1.6.6
- Removed + / - zoom controls from the OpenStreetMap route view. Pinch zoom remains available.
- Monthly flight-time card now follows the current month instead of hard-coded June.
- Today’s Duty now shows only current-date active duties. Future duties do not appear before 00:00 on the roster date.
- Added OFF blocks to Roster and Calendar.
- Reserve duties now open a details page with reserve period and airport crew hotel location.
- Added THAI airline badge styling on flight cards.
- Added aircraft age to Fleet cards.
- Added Pilot Licenses: PPL, CPL, ATPL.
- Added Type Rating issue dates: A320 Family in 2022; A330 and A350 in 2025.
- Replaced VLEK wording with Class 1 Medical Certificate.
- Replaced ASP wording with Safety & Emergency Procedures.
- Added Class 1 medical certificate profile field.
- Updated qualification validity dates: medical in August 2026, simulator in July 2026, emergency procedures in October 2026.
- Added quick Dark Theme switch above UTC toggle on the Roster screen.
- Updated app version references to 1.6.6.
