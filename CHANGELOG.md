# Crew Portal Change Log

## 1.6.7
- Added THAI logo badge on flight cards.
- OFF duty blocks in Roster are no longer clickable.
- Route map keeps pinch zoom but hides + / - buttons and labels A departure / B arrival.
- Improved dark-theme contrast across Roster, Calendar, Fleet, Weather and Profile.
- METAR / TAF cards now use theme-aware colors instead of white cards.
- Added Refresh controls for roster synchronization and weather refresh.
- Expanded pilot license records: IR(A), MEP(L), MCC, UPRT, ICAO English and Radio Telephony.
- Updated app version references to 1.6.7.
