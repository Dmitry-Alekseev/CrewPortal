# Crew Portal Changelog

## 1.8.0
- Added Leave Management: annual leave, personal leave and sick leave controls.
- Added dynamic monthly flight-time target adjusted by approved leave and sick leave.
- Added annual leave calendar with March/September company-assigned leave blocks.
- Added personal leave request flow with confirmation and approval simulation.
- Added sick leave open/close controls with duration calculation.
- Roster now hides duties blocked by approved leave and shows leave blocks instead.
- Calendar keeps full month history and shows flights, OFF, leave and sick leave.
- Today’s Duty now supports pre-flight, in-flight, turnaround and leave states.
- Gate/Stand visibility improved: shown only for first leg or layover/long-haul returns.
- Added realistic layover hotel names and BKK reserve hotel.
- Weather tab now includes operational interpretation of METAR/TAF and runway condition estimate.
- Captain assignment fixed to Dmitrii Alekseev for all rostered flights.
- Added Line Check record in Profile.
- A321neo operation class updated to SHORT / MEDIUM.
- New launcher icon added.
- Backup disabled in manifest.
